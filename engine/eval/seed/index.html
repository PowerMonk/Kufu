What is Kufu?

An experimental coding assistant exploring whether multiple constrained local language models can cooperate to perform small software tasks effectively.

The Agents

Planner

Decides what should happen and creates structured tasks. Never writes code.

Implementer

Receives tasks and modifies code. Never creates plans.

Reviewer

Validates if the plan was executed properly. Never rewrites code.
