Build a landing page for Kufu, an open-source local-first coding assistant.

Requirements:
- Single HTML file with embedded CSS (no external stylesheets or scripts).
- Modern, clean tech aesthetic. Dark mode using matte colors: slate/charcoal background with soft pastel accents (lavender, sage green, dusty rose).
- Structure:
  - Hero section with a catchy title and a short subtitle explaining what Kufu is.
  - A section explaining the three agent roles: Planner, Implementer, Reviewer. Each role should have a short description of what it does.
  - A simple footer.
- Technical: semantic HTML5, Flexbox or Grid for layout, fully responsive.
- No JavaScript interactivity required.
