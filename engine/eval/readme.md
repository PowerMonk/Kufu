# Kufu Landing Page Testing Files

This directory contains a simple, intentionally basic ("mid") template for testing local LLMs (like `gemma4:e4b`) to see if they can understand, modify, or expand a landing page for the Kufu project.

## Files Included

- `index.html`: Minimal semantic structure of the Kufu landing page.
- `styles.css`: Basic matte dark mode styles with soft pastel accents.

## Intentional Design Choice

The code is explicitly kept short, lightweight, and unoptimized so it serves as a clean baseline for local AI models with smaller context windows to process and refactor.
